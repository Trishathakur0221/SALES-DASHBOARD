Sales Executive Performance Dashboard

Project Overview

An interactive Excel dashboard designed to analyze sales executive performance across different cities.

Tools Used

- Microsoft Excel
- Pivot Tables and Pivot Charts
- Slicers
- Data Visualization

Key Features

- City-wise sales analysis
- Sales executive performance comparison
- Target achievement percentage analysis
- Interactive dashboard filtering using slicers
- Pie chart and line chart visualizations

Project Structure

- "Sales_Dashboard.xlsx" — Excel dashboard and raw data
- "screenshots/" — Dashboard preview images

How to Use

1. Download the Excel workbook.
2. Open it in Microsoft Excel.
3. Use the city slicers to filter the dashboard.
4. Review sales performance and target achievement metrics.

Project Objective

To create an interactive dashboard that makes sales performance analysis easier and supports data-driven decision-making.
